# 🍎 Food Calorie Recognition

This project focuses on building a **food calorie recognition system** that can classify uploaded food images into categories like **fruits** and **vegetables**, predict the **exact food item**, and retrieve its **calorie information**. The system is deployed through a **Streamlit web interface**, making it easy for users to interact with.

---

## 📊 Project Features

### 1. **Food Classification Using Deep Learning**
   - A deep learning model trained on a labeled food image dataset to classify food into **fruits** and **vegetables**.
   - The model further predicts the specific food item from the uploaded image.

### 2. **Calorie Information Retrieval**
   - After classification, the app retrieves **calorie information** for the predicted food item.
   - This feature helps users get **calorie estimates** for their meals in real-time.

### 3. **Streamlit Web Interface**
   - A **Streamlit-based web app** allows users to upload food images directly.
   - The app displays:
     - **Predicted Food Category** (Fruit/Vegetable)
     - **Specific Food Item Name**
     - **Estimated Calorie Count**
   - Designed to be user-friendly and accessible for health-conscious users.

---

## 🧰 Tech Stack

- **Python** - Core language for model training and app logic.
- **Streamlit** - For the interactive web interface.
- **TensorFlow/Keras** - For training the deep learning model.
- **OpenCV** - For image preprocessing.
- **Pandas** - For managing and retrieving calorie data.
